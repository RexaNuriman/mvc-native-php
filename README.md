# MVC Native PHP

## Deskripsi
Project aplikasi pengelolaan data mahasiswa menggunakan PHP Native dengan arsitektur Model-View-Controller (MVC).

## Teknologi
- PHP Native
- MySQL
- PDO
- XAMPP

## Fitur
- Menampilkan data mahasiswa
- Menambahkan data mahasiswa
- Mengubah data mahasiswa
- Menghapus data mahasiswa

## Cara Menjalankan
1. Jalankan Apache dan MySQL melalui XAMPP.
2. Letakkan project di folder `htdocs`.
3. Siapkan database sesuai konfigurasi pada `config/database.php`.
4. Buka browser dan akses `http://localhost/mvc-native/public/`.

## Struktur Folder
- `app/` — Model, View, dan Controller.
- `config/` — Konfigurasi database.
- `public/` — Entry point aplikasi.
